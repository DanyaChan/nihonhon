# 日本本 (nihonhon) — структура программы

Читалка электронных книг на японском (EPUB, TXT) — статический сайт без
сборки и внешних зависимостей в рантайме (kuromoji лежит локально в `lib/`).
Все скрипты — обычные `<script>` в конце `index.html`, подключаются по
порядку и делят общую глобальную область видимости (без ES-модулей, чтобы
работало и с `file://`).

## Файлы

```
index.html        разметка: тулбар, боковая панель, область чтения, панели
style.css         все стили, включая темы через CSS-переменные
LICENSE           MIT (код проекта)
lib/
  kuromoji.js     токенизатор kuromoji 0.1.2 (сборка из npm-пакета)
  dict/*.dat.gz   словарь IPAdic (~17 МБ), грузится лениво через XHR
  LICENSE-*.txt   лицензия Apache 2.0 и NOTICE kuromoji/IPAdic
js/
  zip.js          распаковщик ZIP
  reader.js       ядро: состояние, пагинация, режимы, показ глав
  epub.js         разбор и отрисовка EPUB
  txt.js          разбор TXT (кодировки, Aozora-фуригана)
  settings.js     панель настроек (цвета, ширина области)
  furigana.js     фуригана по наведению (kuromoji)
  select.js       выделение: фуригана на выделении + перевод
  library.js      недавние книги и закладки
  main.js         точка входа: открытие файлов, обработчики событий
```

## Порядок загрузки скриптов

`lib/kuromoji.js` → `zip.js` → `reader.js` → `epub.js` → `txt.js` →
`settings.js` → `furigana.js` → `select.js` → `library.js` → `main.js`.

`reader.js` определяет общие объекты (`state`, `els`, `$`), которыми
пользуются все последующие модули.

## Модули

### js/zip.js
Класс `ZipArchive` — минимальный распаковщик ZIP для EPUB:
- парсит центральный каталог (EOCD → записи);
- `extract(name)` возвращает `Uint8Array`; deflate распаковывается
  встроенным `DecompressionStream("deflate-raw")`, без библиотек.

### js/reader.js — ядро
Состояние:
- `state` — id книги, заголовок, список глав, текущая глава, blob-URL'ы;
  глава — `{ title, render: () => Promise<Node> }`, рендер ленивый;
- `page` — текущая страница/всего/шаг в страничном режиме;
- `verticalMode` — направление текста (false: слева направо,
  true: 縦書き сверху вниз, столбцы справа налево);
- `scrollMode` — режим отображения (false: по страницам,
  true: бесконечный скролл).

Страничный режим:
- `paginate()` — глава раскладывается CSS-колонками ровно в размер окна
  (`column-width` = ширина области; в вертикальном режиме = высота,
  колонки в vertical-rl укладываются по вертикали);
- `goToPage(i)` — листание сдвигом `#flow` через `transform`;
- `showChapter(index, {atEnd, atPage, anchor})` — рендер главы + пагинация.

Режим бесконечного скролла:
- `showChapterScroll()` — глава кладётся в обёртку `.chapter-block`;
- обработчик `scroll`: возле конца прокрутки `appendNextChapter()`
  дописывает следующую главу; `fillViewport()` добивает короткие главы;
- `updateVisibleChapter()` (дебаунс 200 мс) — определяет главу и
  абзац-якорь у начала видимой области, обновляет TOC/счётчик/сохранение;
- `scrollToAnchor()` — восстановление позиции по номеру абзаца.

Сквозная нумерация страниц:
- `buildPageMap()` — в фоне рендерит каждую главу в скрытый контейнер
  `.flow.flow-measure` с теми же стилями и считает её страницы;
  результат — `pageMap` (страниц на главу). Пересчёт по сигнатуре
  (`schedulePageMap`): книга + размеры + шрифт + направление;
- в страничном режиме номер = сумма страниц предыдущих глав + текущая;
- в скролле: `computeScrollBreaks()` предпосчитывает позиции строк,
  где начинается новая страница (окно на `BREAKS_AHEAD`=20 страниц
  вперёд, снап к сетке строк по прямоугольникам абзацев и line-height),
  `scrollPageNumber()` ищет последний разрыв перед концом видимой
  области. Кэш инвалидируется при подгрузке глав и смене вёрстки.

Прочее: `getCurrentPosition()` для закладок, `clipTitle`, `textWithoutRt`,
`loadBook()` (заполняет TOC, восстанавливает позицию из localStorage).

### js/epub.js
- `openEpub(file)`: `META-INF/container.xml` → путь OPF → метаданные,
  manifest, spine; названия глав из nav-документа (EPUB3) или NCX (EPUB2);
- `renderEpubChapter()`: XHTML → DOM (`DOMParser`), скрипты/стили книги
  удаляются, картинки достаются из архива и подставляются blob-URL'ами,
  внутренние ссылки превращаются в переходы между главами;
- `resolvePath()` — относительные пути внутри архива.

### js/txt.js
- `openTxt(file)`: определение кодировки перебором с `fatal: true`
  (UTF-8 → Shift_JIS → EUC-JP), разбивка на куски по ~20 000 символов
  (`TXT_CHUNK`) — они выступают «главами»;
- `appendWithAozoraRuby()` — фуригана формата Aozora Bunko
  (`漢字《かんじ》`, `｜語《よみ》`) превращается в `<ruby>`.

### js/settings.js
Панель ⚙: цвет текста/фона области чтения и ширина текстовой области.
Пишет CSS-переменные `--reader-fg`, `--reader-bg`, `--content-width`
на `:root`; хранится в `nihonhon:settings`; смена ширины дёргает
`repaginate()`.

### js/furigana.js
Фуригана по наведению:
- словарь kuromoji грузится лениво при первом наведении
  (`dicPath` строго относительный — `path.join` внутри kuromoji
  калечит абсолютные URL);
- позиция курсора → символ (`caretPositionFromPoint`), абзац
  токенизируется (кэш последнего абзаца), слово с кандзи оборачивается
  во временный `<ruby class="hover-ruby">`, при уходе курсора DOM
  возвращается в исходное состояние (`normalize()`);
- во время выделения текста DOM не трогается.

### js/select.js
Выделение текста (мышь и тачскрин):
- запуск: мышь — `mouseup`; касания — дебаунс `selectionchange` +
  `pointerup` (ожидание, пока палец отпущен и выделение устоялось);
- `annotateSelection()` — все слова с кандзи в выделении получают
  `<ruby>` (обёртка справа налево, чтобы не устаревали смещения);
- перевод выделенного на английский: Google Translate (неофициальный
  endpoint) с фолбэком на MyMemory; текст берётся без `<rt>/<rp>`
  (`selectionTextWithoutRuby`), результат — в поп-апе `#translate-pop`.

### js/library.js
- Недавние книги: сами файлы в IndexedDB (`nihonhon` → store `files`,
  ключ — id книги), список в `nihonhon:recent` (максимум 10, старые
  файлы выселяются), меню 📚; `reopenLastBook()` — автозагрузка
  последней книги при старте (`nihonhon:lastBook`);
- Закладки: кнопка 🔖 сохраняет `getCurrentPosition()` в
  `nihonhon:bm:<id>`; список в секции «しおり» боковой панели.

### js/main.js
- `openFile(file)` — диспетчер по расширению (.epub/.txt) + запись
  в недавние;
- обработчики: кнопки тулбара, клавиатура (стрелки листают страницы;
  в вертикальном режиме ← вперёд/→ назад), колесо (страничный режим —
  листание; скролл+вертикаль — горизонтальная прокрутка), drag&drop,
  ресайз (дебаунс → `repaginate`), размер шрифта A−/A＋.

## Идентификация книги и хранилище

Id книги: `"<epub|txt>:<имя файла>:<размер>"` — общий ключ для всего.

| Ключ                    | Где          | Что                                   |
|-------------------------|--------------|---------------------------------------|
| `nihonhon:<bookId>`     | localStorage | позиция: глава, страница, якорь-абзац |
| `nihonhon:bm:<bookId>`  | localStorage | закладки книги                        |
| `nihonhon:recent`       | localStorage | список недавних книг                  |
| `nihonhon:lastBook`     | localStorage | id последней книги (автозагрузка)     |
| `nihonhon:settings`     | localStorage | цвета, ширина области                 |
| `nihonhon:fontSize`     | localStorage | размер шрифта                         |
| `nihonhon:vertical`     | localStorage | направление текста                    |
| `nihonhon:scroll`       | localStorage | режим отображения                     |
| БД `nihonhon`/`files`   | IndexedDB    | файлы недавних книг (по bookId)       |

## Ключевые приёмы вёрстки

- Пагинация — CSS multicolumn: `column-width` = размеру окна чтения,
  «страница» = колонка, листание — `transform` без перерисовки текста;
  в vertical-rl колонки укладываются по вертикали (проверено), поэтому
  там листание по Y.
- Вертикальное письмо — `writing-mode: vertical-rl` на `#flow`
  (в скролл-режиме — на самом скролл-контейнере `#reader.scroll-v`,
  чтобы прокрутка шла влево нативно).
- Стили текста висят на классе `.flow`, а не на id — их разделяют
  видимый поток `#flow` и скрытый измеритель `.flow-measure`.

## Деплой

Статика, GitHub Pages (ветка `main`, корень). Для локальной разработки
нужен HTTP-сервер (`python3 -m http.server`): с `file://` не работают
XHR словаря kuromoji (в Chrome) и местами IndexedDB. Перевод выделения
требует интернета; фуригана после загрузки словаря работает офлайн.
